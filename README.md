# Web portfolio — Deepak A.

Concept and client-style builds, one folder per site. Each static folder deploys as its own site (Vercel: import this repo, set **Root Directory** to the folder, framework preset **Other**).

| Folder | What it is | Platform |
|---|---|---|
| `halfstep-store/` | Halfstep — sneaker store preview with a real-time 3D product | Shopify (theme source in `shopify-theme/`) |
| `shopify-theme/` | Halfstep Shopify theme (Online Store 2.0, built on Dawn) + product CSV | Shopify |
| `calder-rowe-wp/` | Calder & Rowe — business insurance broker, WordPress block theme + Playground blueprint | WordPress |
| `specials-board/` | Specials Board — course launch landing page with before/after CRO case study | Landing page / CRO |
| `webflow-reference/` | Slotted — SaaS dispatch tool marketing site (reference build of the Webflow site) | Webflow |
| `framer-reference/` | Overnight — app launch landing page (reference build of the Framer site) | Framer |
| `wix-reference/` | Ondé — hair studio site with bookings (reference build of the Wix Studio site) | Wix Studio |
| `halcyon-nimbus/` | Halcyon Nimbus — 3D product launch page | HTML / three.js |
| `studio-echoframe/` | Studio EchoFrame — before/after redesign for an architecture studio | HTML |
